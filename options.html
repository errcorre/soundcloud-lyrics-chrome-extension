Настройка SoundCloud Lyrics

Для поиска треков расширение использует официальный Genius Search API. Нужен бесплатный личный токен:

  1. Откройте genius.com/api-clients и войдите (или зарегистрируйтесь).
  2. Нажмите «New API Client», заполните любое имя приложения и URL сайта (например https://soundcloud.com).
  3. Скопируйте значение Client Access Token.
  4. Вставьте его ниже и нажмите «Сохранить».
